# shiosai° 手機版

手機遊玩網址：https://shiosai-shrine-cove.jjuyp.chatgpt.site

這是私人 Sites 網站，需要使用建立此作品的同一個 ChatGPT 帳號登入。用手機瀏覽器開啟即可，不必傳送 HTML 或啟動電腦上的伺服器。

- **單指滑過水面**：產生漣漪，鏡頭保持不動。
- **點擊水面**：水花、推動浮落物，錦鯉會避開。
- **雙指移動及捏合**：旋轉視角、縮放場景。
- **底部控制列**：重設、換季、切換潮汐、開啟設定。
- **設定面板**：可上下捲動；調整光線、粒子與水體。

手機版保留在 `index.html`，仍是單檔、免建置；需要連網載入指定 Three.js CDN。與線上部署內容相同。

本次修正包含手勢分工、44 px 觸控按鈕、安全區域、橫向配置，以及不支援全螢幕時隱藏按鈕。

已使用 Chrome 原生觸控事件模擬測試 375×667、390×844 直向及 844×390 橫向。單指滑動產生 15 次漣漪事件，鏡頭位移為 0；點擊產生 1 次 splash；雙指能改變鏡頭，且沒有誤觸 splash。設定捲動與粒子開關通過，瀏覽器錯誤為 0。完整數值見 `phone-verification.json`。

尚未在實體 iPhone、Android 或 Safari 上測試；觸控模擬效能不能視為實體手機效能。

部署版本：`4949b0b5f08bbc1a9aa6298ec837b1cb22f4a304`。
